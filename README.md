# TWC Connect — Unofficial Concept Prototype

This is an unofficial demo concept, not an official TWC website.

## Quick test
1. Extract this ZIP.
2. Open `index.html` in your browser. This version has the CSS and JavaScript embedded directly in the HTML, so its styling and interactions should still work even if you move only `index.html`.

## Publishing to GitHub Pages
Upload all three files (`index.html`, `styles.css`, `app.js`) to the root of your repository. The `index.html` is standalone, so it also works on its own; keeping the separate CSS/JS files is useful if you later want to edit the design and behavior separately.

Before any official use, TWC should review and verify the content, campus details, service times, branding, and slogan.
